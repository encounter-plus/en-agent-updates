# en-agent-updates

Технический репозиторий подписанных автообновлений en-agent для Windows.

**Для установки скачайте EXE или ZIP из [Releases en-agent](https://github.com/encounter-plus/en-agent/releases/latest).** Файлы этого репозитория вручную скачивать не нужно.

В Releases хранятся подписанный Ed25519 манифест `channel.json` и файлы комплекта с именами SHA-256. Приложение проверяет подпись доверенным ключом и хеш каждого файла, подготавливает обновление и применяет его при следующем запуске.

Исходники, инструкции и сообщения об ошибках: [encounter-plus/en-agent](https://github.com/encounter-plus/en-agent). [Порядок выпуска](https://github.com/encounter-plus/en-agent/blob/main/docs/releases.md).

Приватные ключи, аккаунты, чаты и игры сюда не публикуются. Технические assets опубликованных выпусков нужны клиентам; не удаляйте их.
